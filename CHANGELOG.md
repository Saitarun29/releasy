# Changelog

## 0.1.0 (2025-07-29)

### 🚀 Initial Release

- **GitHub Repository Analysis** — Fetch repository metadata, releases, commits, and pull requests via the GitHub REST API
- **Commit Categorization** — Automatically group commits into Features, Bug Fixes, Performance, Refactoring, Documentation, Dependencies, and Other
- **AI Content Generation** — Generate 4 marketing assets (changelog, LinkedIn post, X thread, email) from a single repository analysis via Mistral AI
- **Export Options** — Copy to clipboard, download individual Markdown files, or download all assets as ZIP
- **Premium UI** — Glassmorphism design with dark mode, animated loading states, and responsive layout
- **SEO Optimized** — Full OpenGraph, Twitter Card, and metadata for social sharing
- **MIT Licensed** — Free to use, modify, and distribute
