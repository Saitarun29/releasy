### Common Questions

**Q: Do I need a GitHub token?**
No. Releasy works with public repositories using the unauthenticated GitHub API.

**Q: How do I get a Mistral API key?**
Sign up at https://console.mistral.ai and create an API key. The free tier provides enough credits for extensive testing.

**Q: Can I use this with private repositories?**
Currently only public repositories are supported. Private repo support may be added in the future.

**Q: Where is my data stored?**
Recent repositories, favorites, and history are stored in your browser's localStorage. No data is sent to any server except the GitHub and Mistral APIs.
